# 🌍 Tourism Website

A responsive tourism website built using HTML, CSS, and JavaScript. It showcases tourist destinations in an elegant, clean UI for a better user experience.

## 🚀 Features

- Fully Responsive Design
- Toggleable Navigation Menu
- Mobile-Friendly Layout
- Clean and Simple UI
- Basic JavaScript Interactivity

## 💻 Tech Stack

- HTML5
- CSS3 (with media queries for responsiveness)
- JavaScript (vanilla)
